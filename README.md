# Simple Linear Regression

A beginner-friendly Machine Learning project implementing **Simple Linear Regression** using Python and Scikit-learn.

This project was created to understand the basic workflow of a Machine Learning model — preparing data, training the model, making predictions, and checking the learned parameters.

## 📌 Project Overview

In this project, a Linear Regression model is trained using a simple dataset where:

* **X** represents the input feature.
* **y** represents the target/output.
* The model learns the relationship between X and y.
* After training, the model is used to predict a new value.

### Example

If the model learns a relationship such as:

```text
X → y
1 → 2
2 → 4
3 → 6
4 → 8
5 → 10
```

It can use this learned relationship to predict the output for a new input such as `6`.

## 🛠️ Technologies & Libraries Used

* **Python** — Programming language
* **NumPy** — Used for creating and handling numerical arrays
* **Scikit-learn** — Used to build and train the Linear Regression model

## 🤖 Machine Learning Algorithm

### Simple Linear Regression

The project uses **Simple Linear Regression**, a supervised learning algorithm used to model the relationship between one input variable and one target variable.

The model learns a best-fit line from the given data and uses it to make predictions.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/kamijarwar/simple-linear-regression.git
```

Move into the project directory:

```bash
cd simple-linear-regression
```

Install the required libraries:

```bash
pip install numpy scikit-learn
```

## ▶️ How to Run

Run the Python file:

```bash
python linear_regression.py
```
